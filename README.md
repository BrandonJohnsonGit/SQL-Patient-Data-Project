# SQL-Patient-Data-Project
In this project, I used a dataset with over 1000 rows of information about various patients and analyzed the data in SQL. The dataset used included many different pieces of information about the project ranging from the patient ID, the medications they use, their age, and many more. The data was predominantly concerned with OCD, as well as other related issues such as depression and anxiety.

Using SQL, I was able to not only see the data, but work with it to try and find different pieces of information. This ranged from finding the count of patients by gender, the average obs score by gender, the most common compulsion type, and a handful of other pieces of information. I had to use many basic SQL techniques to make sure I was using the data properly, like rounding decimals to two places and working with the data for the date properly.

The csv file with the patient data is included, as well as the SQL file. It is worth noting that this project is intended to be used in the MySQL Workbench program.
